This quickstart walks you through the core mntpack workflow: syncing a tool directly from a GitHub repository, verifying the shim, checking what is installed, and keeping things up to date. By the end you will have a working global tool installed via mntpack and a solid mental model of how the system works.

We'll use [ripgrep](https://github.com/BurntSushi/ripgrep) — a fast Rust-based search tool — as our example. The same commands work for any GitHub repository regardless of language.

## Install and run your first tool

<Steps>
  <Step title="Sync a tool with a global shim">
    Use `mntpack sync` (or its aliases `add` / `install`) with the `-g` flag to install a tool and create a global shim in `~/.mntpack/bin/`:

    ```bash
    mntpack sync BurntSushi/ripgrep -g
    ```

    mntpack will:
    1. Clone `https://github.com/BurntSushi/ripgrep.git` into `~/.mntpack/repos/BurntSushi/ripgrep`
    2. Detect the project type (`Cargo.toml` → Rust driver)
    3. Build with `cargo build --release`
    4. Store the binary in `~/.mntpack/store/sha256/<hash>/rg`
    5. Create the global shim `~/.mntpack/bin/rg`

    <Tip>
      You can use three input formats interchangeably: `ripgrep` (repo name only, uses `defaultOwner`), `BurntSushi/ripgrep` (owner/repo), or the full URL `https://github.com/BurntSushi/ripgrep.git`.
    </Tip>
  </Step>

  <Step title="Verify the shim">
    Confirm the shim is on your PATH and the tool runs correctly:

    ```bash
    rg --version
    ```

    You should see output like `ripgrep 14.x.x`. If the command is not found, make sure `~/.mntpack/bin` is in your `PATH` (see [Installation](/installation)).
  </Step>

  <Step title="Check what is installed">
    List all installed packages. Add `-g` to show only packages with global shims:

    ```bash
    mntpack list
    ```

    ```bash
    mntpack list --global
    ```

    Each entry shows the package name, the source repository, and the installed version or commit.
  </Step>

  <Step title="Check for available updates">
    Compare your installed packages against the latest upstream commits:

    ```bash
    mntpack outdated
    ```

    Packages with newer commits available will be listed with their current and upstream SHAs.
  </Step>

  <Step title="Update all packages">
    Pull and rebuild all outdated packages at once:

    ```bash
    mntpack update
    ```

    To update a single package by name:

    ```bash
    mntpack update ripgrep
    ```
  </Step>
</Steps>

## Install from a release asset

Building from source gives you the latest commit, but for stable, fast installs you can download a pre-built release asset directly from GitHub Releases. Use `-r auto` to let mntpack pick the right asset for your current OS and architecture automatically:

```bash
mntpack sync BurntSushi/ripgrep -r auto -g
```

<Info>
  `-r auto` performs platform and architecture matching against the available release assets. For most well-maintained projects it will find the correct binary without any manual specification. You can also provide an exact asset filename: `mntpack sync owner/repo -r tool-linux-x64.tar.gz -g`.
</Info>

To upgrade installed packages to their latest release assets (bypassing the source-build flow):

```bash
mntpack upgrade
```

## Pin a specific version

Install a specific tagged release using `-v`:

```bash
mntpack sync BurntSushi/ripgrep -v 14.1.0 -g
```

You can also pin to a commit hash:

```bash
mntpack sync BurntSushi/ripgrep -v 8f3c2a1 -g
```

<Note>
  When you use `-r` (release asset download) together with `-v`, the version must be a tag — commit hashes are not valid release asset identifiers and will be rejected.
</Note>

## Install multiple versions and switch between them

mntpack can maintain multiple installed versions of the same package side-by-side:

```bash
mntpack sync BurntSushi/ripgrep -v 13.0.0
mntpack sync BurntSushi/ripgrep -v 14.1.0
```

Switch the active version (updates the global shim target):

```bash
mntpack use ripgrep 14.1.0
```

Run a specific version once without switching:

```bash
mntpack exec ripgrep@13.0.0 -- --version
```

## Inspect a package

Get details about an installed package (version, shim location, store path):

```bash
mntpack info ripgrep
```

Find which package owns a particular command name:

```bash
mntpack which rg
```

## Remove a package

Uninstall a package and remove its global shim:

```bash
mntpack remove ripgrep
```

All of `remove`, `uninstall`, `rm`, and `unsync` are aliases for the same operation. You can pass a package name (`ripgrep`) or a repo form (`BurntSushi/ripgrep`).

## Run without installing globally

To run a tool ephemerally — without creating a global shim or registering it as an installed package — use `exec`:

```bash
mntpack exec BurntSushi/ripgrep -- --version
```

This clones, builds (or reuses a cached build), and runs the tool in one step.
