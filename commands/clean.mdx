---
title: "mntpack clean — Free Disk Space and Orphaned Repos"
sidebarTitle: "clean"
description: "Free disk space by clearing mntpack's entire cache directory, and optionally removing orphaned repository clones that no installed package references."
---

The `clean` command reclaims disk space by removing files that mntpack accumulates during normal operation. Without any flags it removes the entire `~/.mntpack/cache/` directory — which contains exec artefacts, binary-cache checkouts, and git mirror data — then recreates the empty `cache/`, `cache/git/`, and `cache/exec/` subdirectories. Pass `--repos` when you also want to remove git worktrees for repositories that are no longer referenced by any installed package.

## Synopsis

```bash
mntpack clean [--repos]
```

## Options

<ParamField path="--repos" type="flag">
  In addition to clearing the cache, remove orphaned repository directories under `~/.mntpack/repos/<owner>/<repo>`. A repository is considered orphaned when no currently installed package was synced from it.
</ParamField>

## What Gets Cleaned

<Tabs>
  <Tab title="Default (cache only)">
    Running `mntpack clean` without flags removes the entire `~/.mntpack/cache/` directory and recreates its skeleton:

    | Directory | Notes |
    |-----------|-------|
    | `~/.mntpack/cache/` | Entire cache tree — including exec artefacts, binary-cache checkouts, and git mirror staging — is deleted and the empty directory structure recreated |

    Installed packages, global shims in `~/.mntpack/bin/`, the content-addressed store under `~/.mntpack/store/`, and all repository clones are **not** affected.
  </Tab>
  <Tab title="With --repos">
    Running `mntpack clean --repos` performs the default cache clear and also removes:

    | Directory | Contents |
    |-----------|----------|
    | `~/.mntpack/repos/<owner>/<repo>` | git worktrees for repositories that no installed package uses |

    Repositories still referenced by at least one installed package are left in place.
  </Tab>
</Tabs>

<Note>
  `clean` does not remove installed packages or their build artefacts from `~/.mntpack/store/`. To fully remove a package, use [`mntpack remove`](/commands/remove).
</Note>

## Examples

```bash
# Clear the entire cache directory
mntpack clean

# Also remove repository clones that no installed package references
mntpack clean --repos
```

<Tip>
  Run `mntpack clean --repos` after uninstalling several packages to free the most disk space. You can always re-clone a repository the next time you sync its package.
</Tip>
