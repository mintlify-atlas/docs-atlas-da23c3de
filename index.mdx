mntpack is a GitHub-aware package manager, version manager, and runtime launcher built in Rust. Point it at any GitHub repository and it clones the source, builds using the right language driver, creates globally accessible shims, and keeps everything up to date — all from a single binary.

## What mntpack does

mntpack treats GitHub repositories as packages. Give it a repo in any of these forms and it handles the rest:

```bash
mntpack sync ripgrep              # shorthand (uses defaultOwner)
mntpack sync BurntSushi/ripgrep   # owner/repo
mntpack sync https://github.com/BurntSushi/ripgrep.git  # full URL
```

It detects the project type automatically — Rust, Python, Node.js, .NET/C#, C/C++, or generic — and builds it using the matching toolchain. Binaries are stored in a content-addressed store under `~/.mntpack/store/sha256/` and accessed through lightweight shims.

## Get started in three steps

<Steps>
  <Step title="Install mntpack">
    Build the installer and run it to set up mntpack in `~/.mntpack`:

    ```bash
    git clone https://github.com/mntpack/mntpack.git
    cd mntpack/mntpack-installer
    cargo build --release
    ./target/release/mntpack-installer
    ```
  </Step>
  <Step title="Add ~/.mntpack/bin to your PATH">
    The installer adds this automatically, but open a new terminal or reload your shell profile to pick it up.

    ```bash
    # Verify mntpack is on PATH
    mntpack --version
    ```
  </Step>
  <Step title="Install your first tool">
    Sync any GitHub repository as a managed package:

    ```bash
    mntpack sync BurntSushi/ripgrep -g
    rg --version
    ```
  </Step>
</Steps>

<Tip>
  Use `mntpack doctor` at any time to check your installation health and `mntpack doctor --fix` to automatically repair common issues.
</Tip>
